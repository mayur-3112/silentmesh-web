SilentMesh: kernel-level deception for industrial networks

Deceive, never disrupt. SilentMesh places decoy industrial controllers (Modbus/TCP, S7comm, IEC 60870-5-104, DNP3, OPC UA) and a decoy Windows file share on the plant network. Nothing legitimate talks to them, so any contact is a real signal, recorded with source, protocol and commands.

What it never does

  • It never blocks, drops or delays plant traffic: the kernel program can only pass a packet or hand it to a decoy.
  • It never sits between an HMI and a controller.
  • It fails open: if the software stops, the kernel releases its hook; if it freezes, a kernel lease lapses within about 9 seconds.

Evidence

  • Fail-open tested on every code change on Linux kernels 6.6 to 7.2.
  • 20,000 random plant packets per kernel returned byte for byte, none dropped.
  • 5,937 structured fuzz cases across seven decoys, zero crashes.
  • Modbus decoy median response 95.6 ms against 100.9 ms on a real OpenPLC.
  • External penetration test: two findings, both fixed during the engagement.
